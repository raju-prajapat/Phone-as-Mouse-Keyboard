How to Use

1. Start server.py on the PC.
2. Keep phone and PC on the same Wi‑Fi/hotspot network.
3. Run ipconfig on Windows and find the Wi‑Fi IPv4 address.
4. Enter only that IP here and tap Connect.
5. One finger = move, single tap = left click, double tap = double click.
6. Two-finger tap = right click, two-finger swipe = scroll.
7. Esc/Ctrl/Alt/Tab and arrows are in the top keyboard row.
8. Hold Backspace to continuously delete. Shift changes the visible letters to capitals.
